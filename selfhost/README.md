# 日常集 · 自托管云同步版（selfhost）

与仓库根目录的 [WorkBuddy 资料库版](../index.html) 同一套页面，数据层从 WorkBuddy 资料库换成了**你自己的腾讯云开发（CloudBase）环境**：

- 页面 + 数据全部跑在你自己的腾讯云账号下，域名用你自己的（如 zdzy.xyz）
- 邮箱注册 / 登录，多台设备登录同一账号即可共享同一份数据
- 读写实时写回云端；断网或未登录时自动降级为本地模式，数据不丢
- 全程免费档够用（个人使用 < 200 资源点/月，免费额度 3,000 点/月）

---

## 一、接入你的云端（约 10 分钟）

### 1. 创建免费环境，拿到环境 ID

1. 打开 [tcb.cloud.tencent.com](https://tcb.cloud.tencent.com/)，用你的腾讯云账号登录
2. 「新建环境」→ 选择**免费体验版（¥0/月）** → 记下**环境 ID**（形如 `cloud1-3g1a2b4c5d`）

> 免费环境每半年需要在控制台点一次「续期」，到期前会短信/邮件提醒。

### 2. 把环境 ID 填进页面

打开 `selfhost/index.html`，找到这一行（约第 296 行附近）：

```js
var TCB_ENV_ID = 'YOUR-ENV-ID';   // ←←← 在这里填入你的云开发环境 ID
```

把 `YOUR-ENV-ID` 替换成你的环境 ID，保存。

### 3. 控制台两处配置

集合已建好（第 2 步），剩下这两处也都在 [tcb.cloud.tencent.com](https://tcb.cloud.tencent.com/) 里，**先点进你创建的那个环境**：

| 配置项 | 入口路径 | 填什么 |
|---|---|---|
| **Web 安全域名** | 左侧「环境」→ 顶部「环境配置」标签 → 「安全来源 / 安全配置」→ 「安全域名」区域 → 【添加域名】 | ① 你的部署域名，**不带 `https://`**，如 `work.zdzy.xyz`；② `localhost:8080`（本地调试用，不带端口号的 `localhost` 默认已在白名单）。1~10 分钟生效 |
| **邮箱登录** | 左侧「登录授权」→ 「登录方式」标签 → 找到「邮箱登录」→ 开启 | 开启即可，无需配 SMTP（系统默认发件）。若有「允许邮箱注册」开关请一并打开，否则只能登录不能注册 |

### 4. 本地验证

```bash
cd selfhost
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

预期行为：页面右下角出现登录胶囊 → 首次弹出「连接我的云端」→ 注册一个账号（邮箱 + 至少 8 位密码）→ 连接成功后本地已有数据自动上传云端。

## 二、部署到腾讯云 COS + 自有域名

1. **COS 控制台** → 创建存储桶（地域任选，访问权限：公有读私有写）
2. 上传 `selfhost/index.html` 到存储桶根目录（可用 coscli / 控制台网页上传）
3. 存储桶 → **基础配置 → 静态网站** → 开启，索引文档 `index.html`
4. （推荐）套 CDN：CDN 控制台 → 添加域名，源站指向该存储桶静态网站地址
5. 域名 CNAME 解析到 CDN 分配的 CNAME 地址（zdzy.xyz 已备案，可直接解析）

> 部署完成后，记得回到 CloudBase 控制台把正式域名也加进 **Web 安全域名**。

## 三、数据同步机制

| 场景 | 行为 |
|---|---|
| 首次登录，云端为空 | 本机真实数据全部上传云端（示例数据不上传） |
| 登录时云端已有数据、本机也有未同步记录 | 先补传本机记录，再合并拉取，两边都保留 |
| 日常增删改 | 本机 localStorage 即时保存 + 云端实时写回，双保险 |
| 写入云端失败 | toast 明确提示，数据仍保留在本机，刷新后可重试 |
| 未登录 / 未配置环境 ID | 本地模式，右下角胶囊可随时连接云端 |
| 多设备 | 登录同一账号即共享数据；云端数据以账号（uid）隔离 |

## 四、故障排查

| 现象 | 原因 → 解决 |
|---|---|
| 登录提示「登录未成功」 | 环境 ID 填错 / 控制台未开启邮箱登录 → 检查 `TCB_ENV_ID` 与登录授权配置 |
| 胶囊显示「⚠ 云端读写异常」 | 集合没建全或 Web 安全域名没配 → 按 1.3 节补齐 |
| 控制台报 CORS / 跨域 | 当前访问域名不在 Web 安全域名列表 → 补充后即可 |
| 换设备后数据没出现 | 确认登录的是**同一个邮箱账号**（uid 不同则数据不互通） |
| 免费环境到期 | 控制台「环境 → 续期」，半年一次 |

## 六、与 WorkBuddy 资料库版的区别

| | 根目录 index.html | selfhost/index.html |
|---|---|---|
| 数据后端 | WorkBuddy 资料库（6 张绑定表） | 你的腾讯云 CloudBase（6 个集合） |
| 登录 | WorkBuddy 账号体系 | 邮箱 + 密码（CloudBase Auth） |
| 托管 | workbuddy.link | 你自己的 COS + 域名 |
| 数据归属 | WorkBuddy 空间 | 你的腾讯云账号 |
| 页面功能 | 完全一致 | 完全一致 |
